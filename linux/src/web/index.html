Hardware Key Listening (/dev/input)

To enable system-wide background key listening without root, your user account should be added to the input group.

sudo usermod -aG input $USER

Note: After running this command, log out and log back in for changes to apply.

Systemd User Service (Autostart on Boot)

To keep the background service running even when all application windows are closed:

./install_service.sh

Or manually via systemd:

systemctl --user enable knowyourclicks.service
systemctl --user start knowyourclicks.service
